# 交付前检查

1. 实际见到哪些素材、读到哪些音频信息？是否区分了事实、估算和未知？
2. 素材编号真实或已标建议？首帧/产品/人物冲突是否解决？套装数量与首帧造型是否保留？
3. 有没有明确“观众需要看见什么”，而不只是点头、举包装、指脸？
4. 是否完成产品适用的一次真实使用及可辨认停留？未能完成时是否直说原因？
5. 开盖前后、盖子去向、各手任务、承托位置是否连续可执行？是否出现无依据桌面或隐藏操作？
6. 实际产品/内容物外观有依据吗？膏液是否从真实出口/罐口转移并经接触逐渐推开？贴片膜布是否从实际位置取出/承接、展开并经接触贴合？是否避免瞬间出现、消失和变色？
7. 操作是否持续在同一部位？膏液是否从原始点涂处推开，贴片是否保持同一片膜布与同一组孔位、逐步贴合？纹理、光线、曝光和肤色是否连贯？
8. 允许必要的低头、转脸、短暂局部遮挡和包装朝向变化吗？有没有与动作相矛盾的“全程不得接触脸/不得开盖”等规则？
9. 面部是否淡而自然，同时允许说话口型、眨眼和合理表情？
10. 动作数量是否按实际原声、产品和空间取舍？是否为重复操作牺牲核心过程？
11. 原音频是否完整保真，时间线连续覆盖？估计对齐是否标明？是否无额外配音、字幕、BGM和无声片尾？
12. 正式提示词是否独立完整，无占位、无“参考上表”，必要产品细节具体？
13. 是否未把参考视频的人物、产品、台词、78.6秒流程或未知画外路径照搬？
14. 是否没有用生成画面宣称未经证实的即时疗效或长期改善？
15. 只有参考或缺关键输入时，是否交付方法/草案并明确未核实部分，而非虚构最终稿？
16. 成片诊断是否保留成功部分、指出证据与推测，并在修订时给完整提示词？
17. 是否按产品真实用法和演示部位安排正常一次使用量，或遵循用户/可靠产品说明的明确用量？有没有擅自缩成“一小点”“米粒大小”，或在接触时把正常用量变成微小膏点？取用、转移与涂开时间是否匹配？
18. 正式提示词及修订稿的素材映射、正文、时间线和原声约束，图片引用是否全部为 `@图` 紧接实际阿拉伯数字编号（如 `@图1`、`@图2`），没有 `@图片` 旧前缀或字母 x 占位？历史稿及用户旧图片标记是否已规范化且保留原编号对应关系？音频和视频是否仍用各自正确的 `@音频1`、`@视频1` 等引用？是否清除了所有具体文件名、后缀、路径、网址、文件链接和无 `@` 的素材编号？标记是否与实际或已注明的建议映射一致，且没有在括号或书名号内补回文件名？
19. 除非用户明确要求写进提示词，正式稿及修订稿是否已去掉视频比例、输出像素尺寸、横竖屏及铺满/补边/裁切等画幅适配语句？是否避免把首帧测得宽高比当作视频比例？比例留给用户的 API 或平台设置，稿内也不重复参数说明。

20. 是否先确认面膜类型，并在面膜任务中阅读专用动作库？贴片与涂抹动作是否正确分流，类型未知时是否没有把猜测当事实？
21. 贴片是否继承首帧的未拆/已取出/已展开/已上脸状态，不重置包装或凭空长出膜布？是否只添加参考确认的层片、背衬和耳挂？
22. 双手展开、对齐、贴合与抚平是否可执行，包装及废弃物去向是否明确，膜布边缘和眼鼻口孔位是否连续且没有穿透皮肤？
23. 是否把贴合抚平与涂膏揉化明确区分？涂抹式面膜是否保留真实覆盖层，没有默认按摩吸收或凭空洗净？
24. 短原声是否只表现当前真实使用阶段，没有编造完整敷用时间、贴上立刻揭下见效、瞬间变白或消纹？口型与膜布的自然局部活动是否兼容？

验收不以动作越多越好，也不以零失真牺牲全部使用动作。没有生成实测时，只能确认规则、流程和文件已经检查，不能宣称实际视频效果通过。

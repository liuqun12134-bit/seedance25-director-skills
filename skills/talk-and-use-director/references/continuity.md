# 连续性与可执行性

## 状态记录

按关键动作记录：

| 状态 | 必须回答 |
| --- | --- |
| 双手 | 当前各拿什么、承担什么；如何释放或接管；是否真的有自由手 |
| 容器 | 在手/承托面/画外何处；开合；朝向；内容物从哪个出口出来 |
| 盖/配件 | 与容器是一体还是分离；移到哪里；是否挤占操作手 |
| 内容物 | 起点、转移路径、用量、指腹与皮肤残留，是否逐渐摊开 |
| 作用部位 | 起初有无产品、涂在哪里、涂开后覆盖范围；同一部位是否持续 |
| 摄影与原声 | 同机位光线曝光；嘴部可见性；动作能否在原声内完成 |

两个相邻动作的结束/开始状态须匹配。例如，左手托罐、右手开盖之后，不能立即写右手取膏却不交代盖子由谁接管。首帧双手举两件物体，不能凭空多出空闲手；可规划有依据的放置路径或减去非必要持物，但不能让物体消失。

## 面膜的连续状态

面膜按类型维护状态，不能只追踪“膏体在哪里”。贴片式记录：包装开口及去向→膜布在袋内/手中/脸上→折叠与展开程度→已确认的膜布层数、背衬与取下位置→双手捏持的边缘→眼鼻口孔位及局部接触区域→已贴合/待抚平的边缘。涂抹式则记录真实容器、取用工具、内容物和覆盖层。

取出后保持同一片（或有依据的同套分区片）的身份和拓扑，允许湿膜布随重力自然垂落、起皱与贴脸弯曲，不要求像硬板一样完全不变形。未贴合区域不能提前吸附或穿过皮肤；孔位不能跟随嘴唇任意移动，鼻翼片不能盖住鼻孔。只有参考明确存在背衬、保护网、耳挂或分区片时才安排这些结构。

拆下的袋角、袋子、背衬和膜布都要有连续去向。双手取膜/展开/贴合前，须有真实可执行的交接或有依据的放置路径；没有可见或已确认承托面时，不凭空补桌面，不让一只手同时完成三项相互冲突的任务，也不让包装出画即自动消失。必要时缩小当前片段的操作范围，并明确首帧条件不足。

说话引起的面部和嘴部运动要与膜布贴合状态兼容，允许局部随皮肤轻微活动；不能为口型清晰让膜布大幅开洞、漂浮、穿唇或换脸。短片只表现当下贴合，不暗示完整敷用时间已经过去。

## 稳定性约束应保护什么

保持：人物同一身份与造型、包装几何结构和设计、合理比例、实际数量、肢体解剖、物理路径、原声完整。

允许连续变化：视线、头部适度转动、手的位置与任务、包装朝向和遮挡、开合、取用后内容物位置、产品在手或承托位置。标签在操作时不必全程正对镜头；应在识别和收尾等适当阶段给清晰展示。

盖体虽为同一商品部件，开盖后可分离为两个实体；不能误写“数量始终只有一个物体”使盖子消失。原有套装/赠品仍需保留对应关系。

## 高风险时的处理顺序

1. 保留核心使用目的，减少一次动作中的同时任务。
2. 减少取用次数和演示部位，选一条明确的接触、推开路径。
3. 简化非必要包装操作，例如首帧本就开盖则不再盖回重开。
4. 若结构、承托或手位仍不支持，给出具体阻碍及可选首帧调整建议。未经授权不编辑首帧。
5. 确实无法完成时明确未达成的使用目标；不能把只拿产品说话伪装成使用版成品。

## 结果边界

同一部位，同一光线曝光与纹理，保留真实皮肤瑕疵和正常阴影。逐渐变薄的膏层可以呈现，功效结论不能由生成画面证明。不能用全脸亮度突变、皮肤重绘、滤镜或不同镜头对照伪造结果。产品性质未知时先指出未知，不依赖未经证实的效果补足画面。

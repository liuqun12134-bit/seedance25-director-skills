# 本版动作参考分析

来源：用户提供的《动作参考视频.mp4》。本次本地媒体检查：78.600秒、720×1408、30fps，含音轨。采用约每2秒抽帧覆盖全片，并在0–6秒与37–44秒补充逐秒观察。以下为画面观察与大致阶段，未转写或核对原视频台词，不能用作词句对齐时间轴。分段边界只便于理解，不代表每个动作的精确起止。

## 可确认的视觉过程

| 参考时间约 | 可见行为 | 可以提炼的方法 |
| --- | --- | --- |
| 0–2秒 | 人物在脸侧举起有盖罐装产品，并指向包装 | 先建立产品识别，不长时间挡脸 |
| 2–5秒 | 产品降低到胸前附近，双手参与开盖；随后罐口朝向镜头，手指接近可见浅色膏体 | 开盖需要明确前后状态；露出内容物后才取用 |
| 6–15秒 | 两颊、额头及下巴逐步出现膏体，期间手指返回罐口附近取用 | 内容物应通过接触转移到皮肤，展示部位逐步累积，不瞬间长出所有膏点 |
| 16–35秒 | 持罐与涂抹交替，手掌/指腹在面颊、额头、下巴移动；目光有时看镜头，有时关注操作 | 主要动作是推开产品，交流嵌在操作中；不必每句重复举产品 |
| 36–44秒 | 产品多次降低或部分离开画面；约42秒可见带盖产品重新展示 | 可以有从演示回到包装介绍的阶段，但画外的盖子收纳和重新盖回细节无法从抽帧完整确认，不应照抄为已知路径 |
| 45–65秒 | 包装不再持续占据主画面；继续在脸颊、鼻翼附近、额头等处进行触摸、涂匀或按压动作 | 允许阶段性把视觉中心交给使用部位；包装不是每秒都必须可辨 |
| 66–78.6秒 | 触摸脸颊、适度转头与面向镜头交替，后段更多直接交流 | 结束前给同一部位看清的时间，再自然收尾 |

## 观察边界

- 表格中的左右只用画面定位；自拍镜像未知，不据此认定解剖左右。
- 能看到开盖前后，但不能从抽帧完全还原盖子去向、每次取膏用量或画外承托面。
- 能看到浅色膏体和逐步涂抹，不能由画面确认其真实成分、功效、吸收机制或品牌小字。
- 本参考的涂抹后外观不能证明淡斑、美白或长期效果；曝光、光照、肤色和面部纹理必须连续。
- 这是动作方法来源，未验证任何 Seedance 生成效果。

## 迁移到新素材的原则

采用“展示包装→让内容物可见→取用并接触→分区推开→展示此时状态→交流收尾”的可选结构，不要求每次全部完成，也不把78.6秒流程等比压缩到短音频。新片可只演示一个部位、一次取用。

继承的是边讲边操作、视线自然切换、产品随阶段改变展示位置、结果有停留。不得继承本视频的人脸、粉色上衣、罐体、背景、内容物颜色、固定手侧、原台词、重复揉搓数量或夸张表情。只有新素材支持才使用对应细节。

参考中的不明确路径在新提示词里必须重新规划，不能复制其未知画外动作。本插件不携带原始视频、人物截图或声音，只包含这份文字化动作研究。

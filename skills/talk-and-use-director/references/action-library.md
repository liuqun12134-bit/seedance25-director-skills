# 可组合的使用动作

这是动作方法库，不是每条必选的流水线。按真实音频、首帧、产品用途、时长和空间选择。先确认使用类型；下文取用、点涂与推开的单元只适用于产品真实允许的形态，不是所有化妆品的通用步骤。遇到面膜必须同时阅读 [面膜专用动作库](mask-action-library.md)，先分清贴片式、涂抹式与其他特殊形态。

## 动作单元语法

`观众需要看什么 → 起始状态 → 手/产品运动路径 → 接触与内容物变化 → 可辨认停留 → 结束状态/下一步`

手位必须按新首帧重新判断。一个动作一条清楚的主路线，避免同时开盖、怼镜头、涂脸和大幅转头。操作期间允许短暂看手；关键结果再回看镜头。

## A. 包装到内容物

- 有盖罐：从实际握持开始，双手协作完成合适的旋开或拔开动作；盖体路径及去向明确；罐口轻微朝向镜头露出内容物，不能倾倒未确认可流动的产品。
- 软管：管盖/翻盖以真实结构开启；出口朝向可用指腹或演示部位；单次轻压挤出适量，膏体从出口连续形成并落到接收位置；管体只在受力处合理变形。
- 泵瓶：确认解锁状态和泵口方向；接收手或演示部位位于出口下方，再按压一次；不让没有接收位置的液体悬浮。
- 滴管：只有滴管结构、液体性质及手部空间有依据才选；描述吸取/提起/滴落的连续路径。复杂度过高时改选产品真实允许的更简单用法，不把滴管改成泵头。
- 用户已确认开盖/有膏的首帧：直接进入取用或推开，不重复开启或凭空补盖。

## B. 取用与质地

指腹接近实际内容物，实际接触并按产品真实用法和演示部位取起正常一次使用量；指腹离开时携带清楚可见的内容物。不要默认写成“少量”“一小点”或“米粒大小”，也不要为了画面夸张而超出正常用量。用户或可靠产品说明已给用量时按其执行，未知时不编造克数或固定颗粒尺寸。需要质地展示时，在镜头可辨认的距离短暂停留，避免指头和产品透视夸张。颜色、稠度、拉丝、颗粒和透明度必须有依据，不为戏剧效果强加未经确认的质地特征。

## C. 接触与点涂

携带内容物的手指沿连续路径来到已入画部位，实际接触皮肤后转移相应用量，指腹残留相应减少；不在这一环节把正常取用量自动缩成微小膏点。点一处或少数部位就可成立，不默认照搬参考视频额头、双颊、下巴全套。脸上原有膏体不得重置或换边。

## D. 推开与涂匀

从实际膏点位置开始，指腹或适合的掌面接触皮肤，沿一条短路线推开，再沿同方向或局部打圈延展，为正常用量逐渐铺开留出真实操作时间。厚膏点逐渐成为更薄、更宽的覆盖层；不能手没碰到就自动均匀，也不能一下全部消失。手指随面部表面弯曲，皮肤纹理保留；不穿过鼻子、嘴唇或眼睛。

不是所有产品都应按摩吸收：遮瑕、隔离、防晒、面膜、清洁类各有不同用途；按可靠产品信息安排。油、液、泡沫、粉末同理，不自动套用膏霜逻辑。

## E. 让观众看清结果

操作手离开目标区域，人物保持同一光线和曝光，轻微转到能看清的角度并短暂停留。只展示有依据的即时外观，如覆盖均匀度、残留、薄层或合理光泽。不能用“干净透亮”暗示未提供的功效或改变肤色纹理。轻触可表达表面状态，但不能凭空用手势证明不黏、吸收或长期改善。

## F. 重新展示与收尾

若产品已放下，按确切位置连续拿回；若一直持有，则平稳抬到可辨位置。盖回不是必做动作，只有时间与结构允许且确有用途才安排。最后一句按原声结束，人物自然稳定，不加无声片尾或额外话术。

## G. 面膜按类型选动作

- 贴片面膜：选择与首帧相接的拆袋、取膜、展开、对齐眼鼻口、实际贴合、局部抚平和贴合展示；膜布持续存在，不取膏点涂、不把膜布按摩吸收。每步前先解决双手与包装去向，双手贴膜时不能额外一直举着包装。
- 涂抹式面膜：按已知质地、工具和真实用法取用并形成正常覆盖层，不默认按摩至消失，不凭空生成刷子、水或洗脸设施。
- 详细动作、起始状态、特殊层片与时长取舍，按 [面膜专用动作库](mask-action-library.md) 执行；没有材料时不编造膜布颜色、背衬或具体敷用时长。

## 不同品类的迁移

| 产品 | 合适的操作核心 | 需要避免 |
| --- | --- | --- |
| 膏霜/乳液 | 取用、点涂、局部推开、同部位展示 | 擅自假定颜色/黏度、瞬间消膏或长期功效 |
| 贴片面膜 | 取出/展开、孔位对齐、贴合、局部抚平、展示当下贴合状态 | 把膜布涂化、孔位漂移、多出一层、贴上立刻揭下见效 |
| 涂抹式面膜 | 按真实用量取用、形成合理覆盖、展示涂层 | 默认揉到吸收、编造洗净过程、与贴片式混用 |
| 彩妆/遮盖产品 | 按正常用量上妆、局部延展、同光线下覆盖状态 | 换脸、磨皮、偷偷改变对照区 |
| 洗护 | 已有条件下取用或演示；湿发、水源等需素材支持 | 画面无水却突然冲洗起泡 |
| 工具/家居用品 | 展示结构、操作一次、呈现可见机械或使用结果 | 无依据新增污渍、道具、安装结构 |

## 时长取舍

短原声优先“一次完整使用+看清结果”。先削减重复取膏、多个部位、反复按摩、二次开合，再考虑是否缺少关键首帧条件；不能删掉所有接触动作后仍称试用。长原声可跨句持续一个动作，穿插交流停顿，避免每句从头重新演示。
